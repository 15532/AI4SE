# IDE Shell V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将 WebUI 从简单模型前端升级为轻量智能 IDE 壳层。

**Architecture:** 继续使用当前 Node HTTP server 与 server-rendered HTML。只修改 view 层与相关测试，不改变 harness core、provider、guardrail、tool dispatcher、SQLite store 或 API contract。

**Tech Stack:** TypeScript、Node.js、Vitest、server-rendered HTML/CSS。

## Global Constraints

- 不引入前端框架。
- 不改变 `/api/runs`、`/api/workspaces`、`/runs/:id` 的既有语义。
- WebUI 仍只能选择预注册 workspace id，不能传入任意 root。
- WebUI 仍不能展示 API key 或 workspace root。
- 方案 B 第一版只做 IDE 壳层，不实现浏览器内代码编辑器。
- 提交前运行 `npm test` 与 `npm run build`。
