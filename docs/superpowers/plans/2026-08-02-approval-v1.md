# Approval V1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 为发布/部署类命令增加一个简单的人类审批门。

**Architecture:** Guardrail 负责把 allowlist 内高风险命令分类为 `require_approval`，核心循环负责暂停 run 并写入审批记录，Web 层负责展示和处理审批决定。审批执行前会重新校验 action，避免审批 API 绕过安全策略。

**Tech Stack:** TypeScript、Vitest、better-sqlite3、Node HTTP server。

## Global Constraints

- 所有 git commit 信息使用中文。
- 不自动 push，由用户手动 push。
- 项目文件和新增文档优先使用中文。
- 服务端部署场景下不得让审批绕过 workspace allowlist、路径边界或密钥保护。
